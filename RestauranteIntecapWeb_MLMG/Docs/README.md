# 🍳 Restaurante Escuela INTECAP - Sistema Web

Bienvenido al repositorio del Sistema de Gestión de Reservas y Administración del Restaurante Escuela INTECAP. 

Este proyecto es una aplicación web transaccional diseñada para manejar los almuerzos del personal, el control de la cocina y la administración general de usuarios mediante un sistema basado en roles.
